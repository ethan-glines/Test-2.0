# North Shore Surf — static demo

A responsive surfing landing page made with plain HTML and CSS. No build step, JavaScript, server, database, or email collection. The disabled signup is a visual example only.

## Publish on GitHub Pages

1. Commit these files and push to `main`.
2. Open your repository’s **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select **main** and **/ (root)**, then **Save**.
5. Wait for GitHub Pages to deploy. Your URL will appear in Pages settings.

For this repository, the expected URL is `https://ethan-glines.github.io/Test-2.0/`.

Open `index.html` directly to preview locally. Edit `index.html` for content and `styles.css` for styling. All local asset paths are relative, so repository subpaths work.

The ocean photograph loads from Unsplash and requires internet access. Photo by Andrew Valdivia: https://unsplash.com/photos/mvIkGMH_mPU

The original Sites-hosted version is separate and is not updated by GitHub Pages deployments.
